# Presenting

Slide Spec makes presenting easy with intuitive and familiar keyboard shortcuts.
If you want the TL;DR - click

If you want to jump right in, click the "Fullscreen Mode" or "Viewport Mode" button, and use the left/right arrow keys to navigate between slides. When you're done, click the `esc` key.

## Presentation Modes

Slide Spec offers 3 presentation modes: Normal, Fullscreen and Viewport.

|Mode|Description|Navigation|Keyboard Shortcut|
|---|---|---|---|
|Normal|This is what you see when you open a presentation.|Keyboard shortcuts, navigation toolbar|N/A|
|Fullscreen|Forces the browser into a true fullscreen mode. |Keyboard shortcuts only, `esc` to exit|`F`|
|Viewport|Expands the presentation to fit the current size of your browser. |Keyboard shortcuts only. `esc` to exit|`P`|

## Navigation

Keyboard shortcuts are available in every presentation mode.
In the Normal presentation mode, there is a toolbar at the top with buttons to advance or go to the previous slide.

|Action|Keyboard Shortcut(s)|
|---|---|
|Toggle Fullscreen Mode|`F`|
|Toggle Viewport Mode|`P`|
|Exit Fullscreen/Viewport Mode|`esc`|
|Next Slide|`right arrow`, `down arrow`, `page down`, `space`, `enter`|
|Previous Slide|`left arrow`, `up`, `page up`, `backspace`|
|First Slide|`home`|
|Last Slide|`end`|

## Mobile Considerations

If using Slide Spec on a mobile device or small screen, presentation modes are disabled.
Swipe gestures are supported.
